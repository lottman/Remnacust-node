# Remnacust Node 1.1.1

Установка через консоль на Ubuntu 22.04 LTS или 24.04 LTS (amd64/arm64):

```bash
curl -fsSL --proto '=https' --proto-redir '=https' https://github.com/lottman/Remnacust-installer/releases/latest/download/installer.sh -o installer.sh && sudo bash installer.sh install-node
```

Сначала создайте ноду в панели. Скрипт спросит её ключ и версию выпуска установщика; Enter выбирает `latest`. [Скачать installer.sh](https://github.com/lottman/Remnacust-installer/releases/latest/download/installer.sh).

Инструкции установки, сборки, совместимость и лицензии: [README репозитория](../README.md).
