# 1.1.32

- Ограничена пауза переподключения приватного Node → Xray API: отсутствие сокета при старте больше не накапливает стандартный gRPC backoff до 120 секунд. Это не сокращает время построения конфигурации самим Core и не заменяет проверку его готовности.
- Принятие конфигурации ожидает завершения извлечения пользователей. При ошибке внутренний индекс помечается неготовым и очищается; ошибочное подтверждение не отправляется. Работающий Core не останавливается.
- Сохранены приватный Unix-сокет, проверки владельца/прав, таймауты внешнего API и выбранное администратором ядро. Встроены Core 1.1.19 и обычный Xray 26.11.9, оба на Go 1.27.4.

## English

- Bounded private Node → Xray API reconnect backoff prevents an initially missing socket from accumulating the default delay of up to 120 seconds. Core configuration construction and readiness checks remain necessary.
- Configuration acceptance now waits for user extraction. Extraction failures clear and invalidate the internal index and propagate to the caller while preserving the running core.
- Private Unix-socket ownership/permission checks, external API timeouts and explicitly selected managed cores are preserved. Bundled Core 1.1.19 and default Xray 26.11.9 remain on Go 1.27.4.
