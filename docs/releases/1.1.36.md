# Remnacust Node 1.1.36

Health-check сообщает свежесть состояния Core отдельно от доступности API ноды. Устаревший успешный кэш не служит новым подтверждением готовности или восстановления; панель может корректно отличать недоступный Core от отвечающего агента. Обновляйте Node и Panel согласованно.

Встроен custom Core 1.1.21 на официальном Xray v26.11.9: исправления Xera/XHTTP, ECH, TLS-сертификатов и Vision, ограничение ожидающих отправок и меньшие стандартные HTTP/2-буферы. Отдельный default runtime сохраняет официальную основу Xray с обновлениями зависимостей безопасности. Сохранены preflight, восстановление состояния, журналы квот и подтверждение готовности Core.

Runtime обновлён до Node.js 26.13.1 LTS с исправлениями безопасности; зависимости, lock-файл и исходный архив Core согласованы. Образ доступен для amd64/arm64. Обновление панели не обновляет удалённую ноду. Отдельно закреплённое managed-ядро может оставаться выбранным: проверяйте активную версию и режим.

Комплект: Node 1.1.36, Core/WASM 1.1.21, Panel/Page 1.1.7.125, Installer 1.2.173. Форматы транспортов и сохранённые настройки не заменяются новыми протоколами.

## English

Health checks expose Core-state freshness separately from Node API availability. A stale successful cache is not fresh confirmation of readiness or recovery, allowing Panel to distinguish an unavailable Core from a responding agent. Update Node and Panel together.

Bundles custom Core 1.1.21 based on official Xray v26.11.9: Xera/XHTTP, ECH, TLS certificate and Vision fixes, bounded pending uploads and smaller default HTTP/2 buffers. The separate default runtime retains the official Xray baseline with security dependency updates. Preserves preflight, state recovery, quota journals and Core readiness acknowledgements.

Updates the runtime to security release Node.js 26.13.1 LTS; dependencies, lockfile and the verified Core source archive are synchronized. Images support amd64/arm64. Updating Panel does not update remote nodes. A separately pinned managed core can remain selected: verify the active version and mode.

Bundle: Node 1.1.36, Core/WASM 1.1.21, Panel/Page 1.1.7.125 and Installer 1.2.173. Existing transport formats and saved settings are preserved.
