# Remnacust Node 1.1.31

Оба встроенных ядра собираются на Go 1.27.4: Remnacust Core 1.1.19 и обычный Xray v26.11.9 из закреплённого официального исходника с проверкой SHA256. Это устраняет GO-2026-6859 в net/http. API и формат конфигурации не меняются. Обновление образа не заменяет отдельно закреплённое managed-ядро: проверьте фактически запущенную версию.

## English

Both bundled cores are built with Go 1.27.4: Remnacust Core 1.1.19 and ordinary Xray v26.11.9 from its pinned official source with SHA256 verification. This addresses GO-2026-6859 in net/http without changing the API or configuration format. An independently pinned managed core is not automatically replaced; verify the running version.
