# Node 1.1.28

Адаптер Zod обновлён до `nestjs-zod` 5.6.0. Удалены устаревшие локальные патчи deepmerge и установочный скрипт, который их применял. Docker-сборка больше не зависит от удалённых файлов патчей.

Проверены настоящая HTTP-валидация DTO, генерация OpenAPI, ограничения чисел и массивов, union-схемы и отбрасывание посторонних полей. Контракты управления нодой, поддержка стандартного и кастомного ядра, постоянное состояние, автономная работа и правила квот не меняются. Встроенное Core 1.1.17 на Xray 26.11.9 сохранено.

Комплект: Panel/Page 1.1.7.110 и Installer 1.2.156. Обновление ноды выполняется отдельно от панели.

## English

Updates `nestjs-zod` to 5.6.0 and removes obsolete local deepmerge patches and their install hook. Docker no longer copies removed patch files. Real HTTP validation and OpenAPI checks cover bounds, unions and unknown-field stripping. Node management contracts, stock/custom core selection, persistent state, offline operation and quotas are unchanged. Bundled Core remains 1.1.17, based on Xray 26.11.9.
