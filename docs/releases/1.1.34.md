# 1.1.34

Исправлен первый запуск после переноса с Remnawave. Публичный API начинает слушать после готовности приватного HTTP-сокета; конфигурация и пользователи подтверждаются только после готовности Xray API. Запросы статистики и изменения пользователей во время запуска получают временный HTTP 503 без обращения к неготовому Core и без ложного подтверждения доставки.

После неудачного bind оставшийся приватный API-сокет удаляется только при подтверждённой остановке процесса, закрытых правах, корректном владельце и отказе соединения. Активные сокеты, символические ссылки и обычные файлы не удаляются. Восстановление checkpoint, квоты, журналы и административная пауза сохраняются. Первая замена процесса может прервать соединения; длительность запуска зависит от сервера и профиля.

Встроен Core 1.1.20 на официальном Xray v26.11.9. Баннер показывает активный binary. Проверены 2788 пользователей, ошибка bind и повтор, оставшийся Unix-сокет, рестарт контейнера, повторная синхронизация без замены процесса и штатный Xray.

## English

Fixes first startup after Remnawave migration. The public API listens only after the private HTTP socket is ready; configuration and users are acknowledged only after the Xray API is ready. Statistics and user mutations receive temporary HTTP 503 during startup without calling an unavailable core or falsely acknowledging delivery.

A stale private API socket is removed only after confirming the process is stopped, ownership and private permissions are correct, and connection is refused. Live sockets, symlinks and regular files are preserved. Checkpoints, quotas, journals and administrative pause remain intact. Replacing the process may interrupt connections; startup duration depends on the server and profile.

Bundles Core 1.1.20 based on official Xray v26.11.9. The banner reports the active binary. Verification covers 2788 users, failed bind and retry, stale Unix socket, container restart, synchronization without replacing the running process, and stock Xray.
