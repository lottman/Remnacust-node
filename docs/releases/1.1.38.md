# Node 1.1.38

- Назначенные IPv4 и IPv6 доступны панели для первого обнаружения, периодической проверки и ручного перескана. Неполный или неуспешный ответ не очищает сохранённые адреса.
- Panel 1.1.7.127 проверяет новые адреса каждые 30 минут. Ручной перескан удаляет только исчезнувшие автоматически найденные адреса; ручные записи, порядок и выключенные подключения сохраняются.
- Защищённый запрос адресов работает при остановленном Xray. Он не запускает Core и не меняет конфигурацию VPN.
- В составе остаётся Remnacust Core 1.1.22 на основе Xray 26.11.9. Изменения формата транспорта и пересборка клиентского редактора для этого выпуска не требуются.

Assigned IPv4 and IPv6 addresses are available for initial discovery, a persistent 30-minute append-only check and an explicit rescan in Panel 1.1.7.127. Failed or incomplete scans preserve saved addresses. The authenticated address query also works while Xray is stopped. Explicit rescans remove only disappeared automatically discovered addresses; manual entries, order and disabled connections remain intact.

This release retains Remnacust Core 1.1.22 / Xray 26.11.9. Existing protocol settings remain compatible.
