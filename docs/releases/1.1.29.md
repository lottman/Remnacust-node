# Remnacust Node 1.1.29

Комплект поставляет Core 1.1.18 на основе Xray v26.11.9. Исправлена версия совместимости REALITY клиента: номер продукта не мешает подключению к штатному серверу с ограничением minClientVer. Проверки аутентификации и заданные серверные границы версии не отключаются. Режим default по-прежнему использует отдельный официальный Xray v26.11.9. Настройки панели, ключи и профили автоматически не переписываются.

## English

Bundles Core 1.1.18 with the REALITY wire-version compatibility fix, retaining authentication and explicit server version bounds. Default mode continues to use the separate official Xray v26.11.9. Existing panel settings, credentials and profiles are preserved.
