# Node 1.1.25

- Runtime и зависимости обновлены для Node.js 26.13 LTS; проверена загрузка Linux LMDB, sockdestroy и nftables native addons без реального VPN/tunnel.
- Образ содержит custom Core 1.1.16 и отдельный штатный Xray v26.10.31. Custom остаётся режимом панели по умолчанию; запрос без поля flavor сохраняет legacy-поведение.
- Выбор binary проходит preflight до изменения процесса. Несовместимые квоты, политики и live port plans отклоняются без удаления журналов или снятия ограничений. Явная смена binary использует restart и проверяемый rollback; несовместимый live apply запрещён.
- Сохраняется проверенное отдельно установленное managed custom-ядро; статус показывает поддерживаемые flavors и фактическое выбранное/работающее ядро. Container boot и supervised restart различают прерванный переход и разрешённую операцию.
- Источники Core перепакованы детерминированно с проверкой vendored uTLS/olcRTC, всех файлов и SHA-256. Состояние offline recovery, сроки доступа и кредит квот сохраняются.

Обновление панели не обновляет удалённую ноду. Сохраняйте `.env`, `SECRET_KEY` и все приватные каталоги состояния. Смена процесса может прервать соединения; проверки startup/native addons не являются реальным суточным сетевым прогоном. Исходники и заметки о выпуске не подтверждают публикацию образов.

- Updates runtime and dependencies for Node.js 26.13 LTS; verifies Linux LMDB, sockdestroy and nftables native addon loading without a real VPN/tunnel.
- Ships custom Core 1.1.16 and separate stock Xray v26.10.31. Custom remains the panel default; requests without a flavor retain legacy behavior.
- Validates binary selection before changing the process. Incompatible quotas, policies and live port plans are rejected without deleting journals or removing limits. Explicit binary changes use restart and verified rollback; incompatible live applies are refused.
- Preserves a verified separately installed managed custom Core. Status reports supported flavors and the actual selected/running Core. Container boot and supervised restart distinguish an interrupted transition from an authorized operation.
- Repackages Core sources deterministically with vendored uTLS/olcRTC inventory, file hashes and SHA-256 verification. Offline recovery state, access expiry and quota credit remain intact.

Updating the panel does not update remote nodes. Preserve `.env`, `SECRET_KEY` and all private state directories. Replacing the process can interrupt connections; startup/native addon checks are not a real day-long network run. Source and release notes do not prove images have been published.
