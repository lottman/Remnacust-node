# Node 1.1.39

Основа: Remnawave Node 3.4.6. Core остаётся 1.1.22 / Xray 26.11.9.

`NFTABLES_TABLE_NAME` задаёт имя таблицы плагинов (по умолчанию `remnanode`). Используйте новое имя для отдельной ноды; смена имени не удаляет прежние правила автоматически. `SUPPRESS_DUPLICATE_INSTANCE_WARNING=true` скрывает предупреждение, но не отключает проверку второго экземпляра и механизм сокетной блокировки. Оба параметра необязательны. После изменения окружения пересоздайте контейнер.

Сохранены собственные проверки готовности ядра, сериализация управления, учёт трафика, IPv6, SOCKS и разделение Lua routing/служебного API. Рабочие ноды не обновляются самой панелью.

## English

Based on Remnawave Node 3.4.6. Optional NFTABLES_TABLE_NAME selects the plugin table (default remnanode); changing it does not automatically remove old rules. SUPPRESS_DUPLICATE_INSTANCE_WARNING hides the warning only and does not disable the instance lock. Existing Core, readiness, accounting, IPv6, SOCKS and Lua routing behavior is preserved. Upgrade nodes separately.
