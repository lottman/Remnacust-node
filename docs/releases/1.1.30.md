# Remnacust Node 1.1.30

Первое применение обычного профиля после восстановления локальной конфигурации теперь обрабатывает подтверждённую несовместимость глобальных настроек. Нода проверяет новую конфигурацию, сохраняет возможность отката и запускает ядро автоматически. После успешного применения разрешение снимается. Неподтверждённые ошибки, тайм-ауты, уже применённые профили и обязательные live-планы не разрешают такой перезапуск.

Это устраняет отдельный ручной перезапуск в данном сценарии миграции или восстановления. Первичная замена процесса может кратковременно прервать соединения. При неудаче запуска проверяется восстановление прежней конфигурации; нода не сообщает об успешном применении нового профиля. Проверки checkpoint, квот, версии доставки и сохранённой паузы администратора остаются обязательными. Комплект сохраняет Core 1.1.18 и официальный Xray v26.11.9.

## English

The first ordinary profile after local checkpoint recovery can replace incompatible global settings after an exact native precondition failure. Configuration validation, private checkpoint checks and verified rollback remain mandatory. The internal permission is cleared after acknowledgement; ordinary later updates, ambiguous errors, timeouts and mandatory live plans cannot use it.

This removes the separate manual restart for this migration/recovery case. Initial process replacement can briefly interrupt connections. Failed replacement verifies recovery and never acknowledges the rejected profile. Quotas, delivery ownership and persisted administrator pause remain enforced. Bundled Core stays at 1.1.18; default Xray remains v26.11.9.
