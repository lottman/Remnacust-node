# 1.1.33

На IPv6-only сервере статистика ноды теперь находит основной интерфейс через `/proc/net/ipv6_route`. Выбирается пригодный default route с минимальной метрикой; отвергаются недоступные и зависящие от source-prefix маршруты. При наличии пригодного IPv4 default route сохранено прежнее предпочтение IPv4. Формат API, правила доступа, host networking, Core и синхронизация пользователей не меняются.

Проверки покрывают IPv6-only статистику, вывод stats query, метрики, отсутствие/ошибки файлов маршрутов и совместимость с IPv4. Linux-проверки выполняются в Source checks перед публикацией комплекта.

Комплект: Panel/Page 1.1.7.122, Installer 1.2.170, Core 1.1.19 / Xray 26.11.9.

## English

IPv6-only nodes now discover the default network interface through `/proc/net/ipv6_route`. The lowest-metric usable default route is selected; reject and source-specific routes are excluded. An existing usable IPv4 default route retains its precedence. API shape, authorization, host networking, Core and user synchronization remain unchanged.

Regression coverage includes IPv6-only rates and stats queries, metrics, missing/unreadable route files and IPv4 compatibility. Linux Source checks gate the release cohort.

Cohort: Panel/Page 1.1.7.122, Installer 1.2.170, Core 1.1.19 / Xray 26.11.9.
