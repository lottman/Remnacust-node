# Node 1.1.22

Встроен Core 1.1.13. Агент сообщает панели поддержку общего предела устройства для маршрутов автовыбора и проверяет её перед применением политики.

Ключи маршрутов могут использовать вход с обычным прямым доступом: включение автовыбора не отзывает прежние прямые ключи. Сохранённая политика требует совместимого ядра при старте, установке другой версии и откате.

Для учёта по получателю требуются панель 1.1.7.93 и обновление подписки клиента. Прямые подключения сохраняют прежние лимиты. Старые данные расхода не перераспределяются. Согласованный установщик — 1.2.131.
